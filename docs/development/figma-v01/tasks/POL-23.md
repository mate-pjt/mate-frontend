## 확정 정책 v1 · 2026-11-23 KST

### 최근 검색어

- **공급원**은 공개 3개 보기에서 사용자가 직접 제출한 현재 탭의 검색어다. 로그인하지 않아도 쓸 수 있다. 앞뒤 공백을 제거한 뒤 길이 1~100인 문자열과 마지막 명시 제출 시각만 기록한다. 목록 결과 건수와 무관하다. 입력 중인 글자, 빈 제출, 초기 URL, 새로고침·뒤로/앞으로 가기, 상세 복귀, 보기·필터·페이지 조작만으로 기록을 만들지 않는다.
- **보존과 순위**는 탭 내 앱 메모리의 최신순 최대 5개다. 같은 문자열을 다시 제출하거나 기록을 명시적으로 선택해 검색하면 그 항목의 시각을 갱신해 맨 위로 옮긴다. 각 항목은 마지막 제출부터 30분이 되면 지우며, 6번째 고유 항목을 넣을 때 가장 오래된 항목을 지운다. 만료된 값은 탭 복귀 뒤에도 표시하거나 다시 적용하지 않는다.
- **계정 경계**는 비로그인 문맥 및 현재 확정된 인증 세션이다. 로그인·로그아웃 시작·계정 교체·세션 종료로 문맥이 끊기면 이전 기록을 즉시 버린다. 비로그인 기록을 계정에 승계하거나 A→B→A에서 A 기록을 되살리지 않는다. 초기 인증 확인 또는 미확정 문맥에는 최근 목록 표시·기록 생성을 보류하고 공개 검색을 계속 제공한다. 같은 문맥의 일반 토큰 갱신과 브라우저 새로고침을 구분한다. 새 문서 로드나 탭 종료 시 기록을 복원하지 않는다.
- **삭제와 개인정보**는 최근 목록의 단건 삭제와 전체 지우기로 즉시 메모리에 반영한다. 현재 입력·결과나 목록 URL에서 직접 지우는 동작과는 별개다. 최근 기록용 서버 저장·브라우저 저장소·교차 탭/기기 공유·분석 수집·로그 추가는 허용하지 않는다. 기존 사용자가 실행한 검색의 `query` URL·`keyword` 요청 및 브라우저 탐색 이력은 각자의 계약을 따른다. 최근 목록에서 지워도 기존 URL·탐색 이력까지 삭제되지는 않는다.
- **재검색**은 기록 항목 선택 시 기존 검색 제출 경로를 사용한다. `query`에 반영하고 첫 페이지로 돌아가며 현재 공개 보기와 나머지 필터를 보존한다. 지우기 버튼·Escape·닫기에는 검색 요청이 없다. 입력란의 지우기와 검색 조건 초기화는 최근 목록 전체 지우기를 대신하지 않는다.

### 관리형 추천과 입력 중 제안

- **이번 지원 상태**는 표시 0건이다. 사용자 D2는 관리형 추천 검토 경로를 선택했다. 추천어 목록, 정렬·표시 상한·필터, 승인자나 데이터 계약까지 확정된 상태는 아니다. 사용자 검색 기록, 공고 목록 결과, 시안 예시, 근거 없는 상수에서 추천을 합성하거나 입력 중 제안을 표시하지 않는다.
- **재개 조건**은 추천 콘텐츠 소유자, 그 소유자가 승인한 목록·출처와 배포·갱신·만료·삭제 기준을 확보하는 것이다. 입력 일치 규칙, 정렬·최대 표시 수, 비로그인 제공 범위, 개인정보 섞임 방지, 결측·실패 처리도 소유자가 승인해야 한다. 공급 방식과 버전·검증 자료가 확인되면 입력 중 프레임과 명시적으로 대조하고 별도의 요구사항 Gate에서 검토한다.
