다음 Task는 **QA-09 재개**다. P0이며 PREP-01/QA-04의 main 선행과 QA-08 선정 예외는 충족하지만 필수 실제 QA 차단이 남았고 QA-09→QA-10 예외가 없어 뒤 Task를 자동 선정하지 않는다. **다음 첫 행동:** 새 대화에서 main/Git·이 재개표·PREP 준비표·ALERT-01~08을 대조하고 별칭/기대값·실행 식별자와 로그인/GET/PUT/DELETE 사용·변경/잔존·복구 범위를 확보해 실제 QA Gate를 다시 작성한다. 이번 대화에서 다음 Task는 시작하지 않는다.
