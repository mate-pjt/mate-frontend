## Git 전달 기준

정책·후속 QA 근거와 WBS 완료·인계를 별도 커밋으로 전달한다. 최종 WBS와 인계를 포함한 문서 재검증·재리뷰, 최종 head의 CI·리뷰·병합 결과는 [작업 브랜치 PR](https://github.com/mate-pjt/mate-frontend/pulls?q=is%3Apr+head%3Adocs%2Fpol-26-feedback-channel-policy)에 연결한다. 사용자 승인 예외는 실제 원인이 확인된 이 PR의 Chromatic 월간 한도에 적용한다. 병합 뒤 로컬 main을 fast-forward하고 원격 SHA 일치와 작업트리를 확인한다.
