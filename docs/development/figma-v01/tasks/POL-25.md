## 2026-11-24 · 사용자 결정 D1과 MVP 정책

- **승인**. 사용자가 이 대화의 정책 질문에 “버전 팝업 제공 — 실제 배포 버전과 ‘최신’ 판정에 사용할 공식 출처를 기준으로 팝업만 제공합니다.”를 선택했다. 08:31 KST에 기록했다. Figma에서 확인한 사용자 진입과 팝업을 이용해 현재 웹 배포 버전을 알려주는 범위다. 첫 조사에서 제시했던 MVP 보류는 추천 이력이다.
- **콘텐츠와 목적지**. `/my`의 서비스 이용안내 카드 내부 팝업이 목적지다. 실제 제공 중인 웹 배포의 표시용 버전을 근거 데이터와 대응한다. ‘최신’ 표시는 해당 배포와 같은 환경·릴리스 채널의 공식 최신값과 일치함이 확인된 경우에 한한다. 시안의 `v1.2.0`, npm 패키지 버전 `0.1.0`, 백엔드 OpenAPI `v1`은 각각 관찰한 값이다. 이 값들을 사용자용 배포 버전으로 승인한 근거는 없다.
- **열람과 접근성**. 팝업 진입은 기존 `/my` 인증 경계를 따른다. 별도 문서 URL과 링크 장애 처리는 적용 대상이 없다. 현재 인증 흐름과 기본 화면에서의 진입, 팝업 제목·닫기·확인 및 닫은 뒤 초점 복귀는 후속 검증 기준이다. 버전 불일치·확인 실패 시 근거 없는 ‘최신’ 표시는 피하고 구체 문구와 재시도 방식은 해당 상태의 승인으로 정한다.
- **정합성**. [S07](#pol-25-evidence) 시안의 팝업 방식과 현행 비활성 카드의 차이를 분리한다. D1은 팝업 제공과 버전의 근거를 승인했다. 문구·실패 상태·카드 디자인의 추가 예외 판단은 소유 요구사항 Gate에서 확인한다.

- **D2 승인**. 사용자가 이 대화에서 “DEV-49 선행 조건으로 넘기기 (추천) — 이번에는 팝업 정책과 승인 조건을 확정하고, DEV-49는 공식 버전 출처·책임과 조회 실패 기준을 확보할 때까지 차단합니다.”를 선택했다. 08:37 KST에 기록했다. 공식 값과 게시·갱신 책임의 구체화, 미확인 상태의 표시·재시도 등은 [DEV-49 자체 Gate](DEV-49.md#dev-49-pol-25-gate)의 필수 조건이다. 사용자가 승인한 정책 판정 범위에는 이 조건의 문서화까지 포함된다.
