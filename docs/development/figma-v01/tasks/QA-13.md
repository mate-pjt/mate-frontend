## 2026-11-05 · 실제 QA 재개 조건

필요한 역할은 테스트 계정/수신처 담당·수신 설정 API/오류 fixture 담당·Mailpit/메일 인프라 담당·백엔드 배포 담당·개발자 승인자·프론트 QA 실행자다. 개인 담당자는 미확인이고 외부 메시지를 보내거나 자원을 생성하지 않았다. Mailpit 경로 제공/사용자 직접 접근 가능 회신은 반영했으며 실제 제한 열람을 검증했다고 주장하지 않는다.
