2026-10-30 KST 최초 사용자 요청과 두 범위 답변을 근거로 편집 전 commentary에서 제시한 실행 Brief다. 아래의 “필수 사례가 남으면 Task 전체 완료/Git 보류”는 최초 차단 판정의 근거이며, 후속 진행 예외와 그 종료 기준은 이 기록 마지막 절에 별도로 남긴다.

- 요구사항: HOME-01~09의 기존 홈 카드/이동/상태/인증 CTA를 현재 테스트 API로 검증한다. 기존 구현·mock/HTTP 대역 결과는 실제 API PASS로 대체하지 않는다.
