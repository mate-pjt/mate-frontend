- `pnpm test tests/notification-repositories.test.ts tests/notification-activation.test.ts tests/notification-path.test.ts tests/http.test.ts` 통과. 4파일 128개는 읽음 후 이동·중복 클릭·실패/복구·계정 수명·안전 경로와 공용 HTTP 동작을 확인한다.
- `pnpm test tests/http-contracts.test.ts -t '읽음 변경 뒤 목록과 미확인 건수가 일치한다'` 통과. 같은 사례의 HTTP fetch 대역과 mock 각 1개를 실행했다. 첫 20건·다음 5건 및 읽음 뒤 상태/건수 변화를 확인했다. 필터와 무관한 13개 테스트는 실행 대상에서 제외했다.
- 전체 로컬 앱 test/lint/build/Storybook은 Markdown 변경에 실행·빌드 영향이 없어 생략했다. 브라우저·Figma 재열람·실제 업무 API와 OAuth는 실행하지 않았다. 게시 OpenAPI 200과 개발 배포 성공 기록은 읽기 자료다. 현재 프로세스 및 실제 업무 응답은 미확보다.
