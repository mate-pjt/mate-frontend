## 최초 재개 점검

사용자의 현행 URL 우선 연결 결정 전에는 공개 연결 조건과 가입 QA 재개 기준을 Markdown에 기록했다. 공개 OpenAPI는 터미널의 첫 요청에서 403, 이후 JSON 요청에서 200을 반환했다. Aside는 브라우저 프로필 연결 오류로 명세 조회에 사용하지 못했다. 오류 메시지에 마스킹된 프로필 식별자가 포함됐으며 작업 기록에는 옮기지 않았다.

최초 점검의 로컬 기본 셸은 Node `26.5.0`·pnpm `11.3.0`이고 저장소 `.nvmrc`와 프런트 CI의 Node는 `22.20.0`이다. Markdown 점검에서는 앱 검사와 새 브라우저·HTTP 대역·실제 가입을 실행하지 않았다. 최초 독립 verifier는 6개 Markdown, 문서 검사 21/21과 `git diff --check HEAD`, 공개 OpenAPI를 확인해 해당 diff에 PASS를 반환했다. 이후 사용자 결정으로 제품 두 파일과 문서를 추가 검증·재검토한다.
